# 2026-VK-EDU-Web-12-Gavrishov-E

Домашнее задание 1 — статическая вёрстка сайта вопросов и ответов AskPupkin.



## Страницы

- `public/index.html` — главная, список вопросов с пагинацией
- `public/question.html` — страница вопроса: ответы, пагинация ответов, форма ответа
- `public/ask.html` — создание вопроса
- `public/login.html` — вход
- `public/signup.html` — регистрация
- `public/user-settings.html` — настройки профиля
- `public/base.html` — общий шаблон (шапка и сайдбар)



## Заметки

В основном использовал bootstrap.
